# zia-din.github.io

Developer website for Enversion Labs games, served by GitHub Pages.

- `index.html`: studio page
- `app-ads.txt`: AdMob publisher verification (must stay at the site root)
- `block-off/privacy.html`: Block Off privacy policy

The Block Off privacy policy is generated from `PRIVACY.md` in the Block-Off
repository; update it there and copy the result here.
